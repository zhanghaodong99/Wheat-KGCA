# Annotation Rules

This document should describe the final expert annotation rules used in the paper.

Key boundary examples:

| Boundary | Rule |
|---|---|
| seedling vs tillering | Assign tillering only when multiple basal tillers are clearly visible. |
| stem elongation vs flag-leaf booting | If the flag leaf is clearly and fully visible, assign flag-leaf booting unless the whole spike has fully emerged. |
| heading vs flowering | Fresh white or yellow anthers have priority and indicate flowering. |
| flowering vs grain filling | Grain filling is assigned when fresh anthers are absent and grains/spikelets show filling evidence. |
| grain filling vs maturity | Maturity requires dominant yellowing/drying of wheat organs, not merely background yellow pixels. |
