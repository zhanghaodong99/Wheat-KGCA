# Wheat-KGCA Contribution Modules

This document records the four contribution modules used to organize the final paper experiments.

## M1. Structured VLM Agronomic Evidence

Input: wheat field image.

Output: structured JSON evidence from a boundary-aware VLM prompt, including:

- predicted stage and second candidate
- confidence and uncertainty reason
- spike status
- anther visibility
- anthesis trace
- grain fullness
- flag-leaf booting clue
- tillering and stem-elongation clues
- plant color and image quality

Purpose:

- Convert expert agronomic rules into machine-readable semantic evidence.
- Keep the VLM as an evidence generator rather than the final classifier.
- Support semantic-vector construction, boundary analysis, and explanation.

Relevant files:

- `experiments/01_vlm_structured_output/prompts/P11_flag_leaf_boundary_strict.txt`
- `src/vlm/stage3_vlm_model_comparison.py`
- `configs/vlm_p11_flag_leaf_boundary.yaml`

## M2. RCA Semantic-Visual Fusion

RCA means Residual Coordinate Attention in the current repository.

Input:

- ConvNeXtV2 visual feature map
- structured semantic vector from VLM/expert evidence

Output:

- recalibrated visual feature or gated semantic residual
- final eight-class logits

Purpose:

- Introduce organ-position awareness while preserving the pretrained visual representation.
- Use residual scaling to reduce the risk of overfitting on a high-baseline dataset.
- Avoid treating VLM output as a simple concatenated feature.

Relevant files:

- `src/models/convnextv2_attention_variants.py`
- `src/models/convnextv2_tiny_res_coordinate.py`
- `src/fusion/semantic_gate.py`

## M3. Knowledge-Constrained Loss

Input:

- model logits
- ground-truth stage label
- optional adjacent-pair auxiliary logits
- optional semantic stage distribution

Output:

- joint training loss

Purpose:

- Keep the main task as eight-class single-label classification.
- Allow uncertainty mainly between adjacent wheat growth stages.
- Suppress unreasonable high probabilities on non-adjacent stages.
- Support ablations of semantic anchor and adjacent-pair auxiliary supervision.

Relevant file:

- `src/training/knowledge_losses.py`

## M4. Boundary-Rule Enhancement

Input:

- expert annotation rule table
- boundary review records
- revised train/val/test manifests

Output:

- consistent labels and boundary-aware prompts
- special evaluation subsets for adjacent-stage errors

Key examples:

- If the flag leaf is clearly visible or unfolded and no spike is visible, assign flag_leaf_booting rather than stem_elongation.
- If spike tip or spike is visible, assign heading unless flowering evidence is present.
- If white or yellow anthers are visible, flowering should be prioritized.
- If plants remain green and grains/spikelets are visibly filled, grain_filling should be considered before maturity.

Purpose:

- Make the expert knowledge explicit and auditable.
- Reduce label noise in adjacent stages.
- Provide credible interpretation for small overall gains under a strong visual baseline.

Relevant files:

- `docs/annotation_rules.md`
- `experiments/01_vlm_structured_output/prompts/P11_flag_leaf_boundary_strict.txt`

## Suggested Ablation Table

| ID | Variant | Main Question |
|---|---|---|
| A0 | ConvNeXtV2 baseline | How strong is the visual-only classifier? |
| A1 | A0 + RCA | Does residual coordinate attention improve organ-aware representation? |
| A2 | A1 + structured VLM semantic gate | Does structured agronomic evidence help visual prediction? |
| A3 | A2 + knowledge-constrained loss | Does adjacent-stage prior reduce unreasonable confusion? |
| A4 | A3 + boundary-rule enhanced labels/prompts | Does revised expert knowledge improve boundary cases? |
| A5 | A4 + CAM analysis | Do attention regions become more agronomically reasonable? |

## Paper Positioning

The final paper should not claim that VLM-only classification replaces the visual model. The central claim is:

> Structured agronomic evidence generated by a VLM can be transformed into a semantic guidance signal. Combined with residual coordinate attention and knowledge-constrained learning, this signal improves boundary-stage recognition and interpretability under a strong ConvNeXtV2 visual baseline.
